⚙️ First-time publishing setup
Real-time multiplayer needs a shared database; a standalone HTML file cannot sync phones by itself. Create a Firebase project, enable Realtime Database and Anonymous Authentication, paste your web config into the script, and publish this HTML. Do not use public read/write database rules.

{
  "rules": {
    "rooms": {
      "$room": {
        ".read": "auth != null",
        ".write": "auth != null"
      }
    }
  }
}
These basic authenticated-room rules are suitable only for a casual prototype, not a secure production game. Anyone who joins can alter room data. Use stronger validation/rules for public use.
